NEW FILES:

1. include/aurora/model.hpp + src/model.cpp — Model class that owns N Meshes:
   - Constructor takes a filesystem path to a model file.
   - Uses Assimp::Importer to load the scene with these post-process flags:
       aiProcess_Triangulate
       aiProcess_GenSmoothNormals
       aiProcess_FlipUVs            // OpenGL convention
       aiProcess_CalcTangentSpace   // for future normal mapping
       aiProcess_OptimizeMeshes
   - On load failure, logs spdlog::error with importer.GetErrorString() and throws std::runtime_error.
   - Recursively walks the scene's node tree, processing each aiMesh into our own Mesh.
   - For each aiMesh:
       - Pulls vertices: position, normal, uv (uv from texCoords[0], or vec2(0) if absent), color (default white).
       - Pulls indices from aiFace.
       - Pulls associated aiMaterial; loads diffuse + specular textures via TextureCache (see below).
       - Constructs a struct holding (Mesh, Material) — call it MeshEntry.
   - Stores the directory of the original file (for resolving relative texture paths in the model).
   - draw(Shader& shader) iterates all MeshEntries: upload material, mesh.draw().
   - RAII cleanup is automatic (Mesh + Texture handle their own GL resources).

2. include/aurora/texture_cache.hpp + src/texture_cache.cpp — avoids loading the same texture twice:
   - Static method get(const std::string& path, TextureType type) → std::shared_ptr<Texture>.
   - Internal map<string, weak_ptr<Texture>>.
   - If path is loaded and live, return existing shared_ptr.
   - Otherwise create new Texture, store weak ref, return.
   - This is important: many model meshes share the same texture, and loading 1024x1024 PNGs many times is wasteful.

3. Update Material to handle missing textures gracefully:
   - If diffuse_map is null, use a 1x1 white fallback texture.
   - If specular_map is null, use a 1x1 black fallback (no specular).
   - Add static white_fallback() and black_fallback() helpers in Texture or Material that lazy-init.
